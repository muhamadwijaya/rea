About

SHARX Data Transfer v1.0.0

Jembatan data dari server (MQTT broker) ke printer CIJ. Data dari server dipecah sesuai Flow Mapping, counter dihitung per template, lalu diteruskan ke printer.

  • Koneksi server via MQTT broker (atau TCP langsung), auto reconnect.
  • Posisi field (operator, template, counter, field custom) bisa diatur.
  • Counter tersimpan per template sampai ganti hari atau Reset Counter.
  • Printer TIJ Protocol 4.8 (TCP/IP atau RS232): load template (1E), isi remote field (1D), sinyal selesai cetak (AB).
  • Setiap selesai cetak, operator, template dan counter yang tercetak dilaporkan ke server.
  • Log harian tersimpan di folder data.
